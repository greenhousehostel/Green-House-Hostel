# SQL Schema Builder Skill
When creating database architectures:
1. **Data Normalization**: Define clear relational tables (e.g., students, ooms, eds, ookings, dmins).
2. **Integrity**: Enforce PRIMARY KEY, FOREIGN KEY, NOT NULL, and UNIQUE constraints.
3. **Performance**: Add indexes on frequently queried search columns (e.g., oom_number, student_id, status).
