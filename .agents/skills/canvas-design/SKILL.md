# Canvas & SVG Design Skill
When building visual layout elements (like hostel seat/room plans):
1. **Vector Cleanliness**: Use crisp inline SVGs or optimized <canvas> contexts.
2. **Dynamic States**: Structure seat/room nodes with distinct visual states (Available, Booked, Selected, Maintenance).
3. **Scalability**: Ensure SVG viewBoxes and canvas coordinate scaling remain sharp across high-DPI displays.
