# UI/UX Pro Max Skill
When designing or updating HTML/CSS interfaces:
1. **Visual Hierarchy**: Clear headline hierarchy (H1 -> H2 -> body), proper whitespace/padding (8px/16px/24px/32px scale), and card depth.
2. **Responsive Layouts**: Use CSS Flexbox and Grid. Ensure mobile viewports (< 768px) stack elements gracefully.
3. **Micro-Interactions**: Add subtle hover transitions (0.2s ease-in-out), distinct active/focus states for accessibility, and animated modal overlays.
4. **Consistency**: Use standardized border-radius (8px-12px), clean drop-shadows, and modern card styling.
