# Theme Factory Skill
When configuring styles:
1. **Design Tokens**: Centralize colors, font families, radius, and shadows in :root inside CSS files.
2. **Palette Harmony**: Maintain primary brand accents, secondary supporting hues, neutral surfaces, and semantic states (success, warning, error).
3. **Theme Switching**: Support smooth switching between dark and light modes using data-theme or media queries.
