# API Scaffolder Skill
When designing API endpoints:
1. **REST Conventions**: Use standard HTTP verbs (GET /api/rooms, POST /api/bookings, PUT /api/rooms/:id, DELETE /api/bookings/:id).
2. **Consistent JSON**: Format all responses predictably: {"success": true, "data": {...}, "error": null}.
3. **Error Handling**: Return appropriate HTTP status codes (200, 201, 400, 401, 404, 500) with clear error messages.
