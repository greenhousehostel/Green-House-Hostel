# Web Design Guidelines Skill
When reviewing or creating HTML/CSS:
1. **Accessibility (a11y)**: Ensure all interactive elements have ARIA labels, image lt attributes, and minimum 4.5:1 color contrast.
2. **Touch Targets**: Buttons and touchable controls must be at least 44x44px for mobile usability.
3. **Semantic Markup**: Use <header>, <main>, <nav>, <section>, <article>, and <button> instead of generic <div> tags where appropriate.
